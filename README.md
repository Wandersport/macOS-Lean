# macOS Lean — Clean Install & Evidence-Based Debloat

> **Research stage — not an installation release.** No debloat preset has been validated on macOS Golden Gate 27.2 on this project’s test hardware.

This repository is developing a reproducible guide to clean macOS installation, selective Apple Silicon optimization, battery testing, and optional advanced debloating.

**Principles:** measurable gains, explicit feature trade-offs, reversible changes, security transparency, and source-backed documentation.

The initial research guide is maintained in the **`draft/v0.1-research`** branch and a draft pull request. Please do not execute unreviewed remote installation scripts or disable System Integrity Protection solely to gain free RAM.

**Target test device:** MacBook Air M4, 16 GB RAM, 256 GB SSD. No benchmark claims have been verified yet.

**Status:** Waiting for sufficient macOS 27.x compatibility evidence and reproducible testing before declaring a recommended version or release.
