# Security policy

macOS Lean is currently a **documentation/research project**, not a verified system utility. It contains read-only diagnostics and local static analysis, and does not need root permissions.

**Security concerns:** open a GitHub issue for non-exploitable documentation problems; for an exploit or a serious supply-chain concern avoid posting reproduction details publicly and contact the repository owner privately through GitHub profile contact methods.

Third-party tools listed here are independent projects. Their code, update channels and security practices are not controlled by macOS Lean. Inspect a pinned upstream revision before executing. Never paste secrets, serial numbers or recovery keys into issues.

The Experimental SIP-off profile knowingly weakens macOS protections and is not the public default. The repository does not advertise protection from malicious scripts or guarantee safe rollback on every macOS build.
